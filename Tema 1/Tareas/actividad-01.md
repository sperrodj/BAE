# Actividad 1. Investigadores del almacenamiento

## Descripción

Cada día utilizamos aplicaciones que almacenan fotografías, mensajes, canciones, compras, partidas, ubicaciones o datos personales. Sin embargo, no toda esta información se guarda de la misma manera.

En esta actividad investigaréis cómo ha evolucionado el almacenamiento de información, compararéis los ficheros con las bases de datos y conoceréis algunos de los modelos y sistemas gestores que se utilizan actualmente.

No es necesario tener conocimientos previos. El objetivo es realizar una primera aproximación al módulo, aprender a seleccionar información relevante y elaborar un documento técnico con vuestras propias conclusiones.

## Organización

- Trabajo por parejas.
- Duración aproximada: entre 80 y 90 minutos.
- Cada pareja entregará el documento elaborado de forma individual.
- Posteriormente, el documento se transformará a Markdown y se incorporará al repositorio de actividades.

## Formato de entrega inicial

El documento podrá realizarse con:

- Google Docs.
- Microsoft Word.
- LibreOffice Writer.

Debe utilizar una estructura sencilla:

- Título principal.
- Encabezados y subencabezados.
- Párrafos breves.
- Listas.
- Tablas.
- Imágenes con pie.
- Enlaces a las fuentes.

No se utilizarán cuadros de texto, columnas, fondos decorativos ni otros elementos que dificulten su posterior conversión a Markdown.

## Segunda fase: conversión a Markdown

Una vez corregido el contenido, cada pareja transformará su documento a Markdown.

La carpeta de la actividad tendrá esta estructura:

```text
actividad-01/
├── README.md
└── img/
    ├── evolucion-almacenamiento.jpg
    ├── ejemplo-fichero.png
    ├── modelo-relacional.png
    └── sqlite.png
```

El archivo `README.md` deberá utilizar:

- `#` para el título.
- `##` para los apartados.
- `###` para los subapartados.
- Listas correctamente formateadas.
- Tablas en Markdown.
- Imágenes guardadas dentro de `img`.
- Enlaces a las fuentes.
- Nombres de archivo en minúsculas, sin espacios ni tildes.

Ejemplo:

```markdown
## Modelo relacional

El modelo relacional organiza la información mediante tablas relacionadas.

![Ejemplo de una tabla relacional](img/modelo-relacional.png)

**Figura 1.** Ejemplo de organización mediante filas y columnas.
```

Posteriormente, esta carpeta se incorporará al repositorio de actividades del módulo.
